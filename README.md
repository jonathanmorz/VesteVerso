O **VesteVerso** é um site de comércio eletrônico focado no setor de vestuário brasileiro. 

> 🎓 **Nota acadêmico-profissional:** Este projeto foi desenvolvido como o **Trabalho de Conclusão de Curso (TCC) do Ensino Técnico em Informática**. Foi construído em equipe, representando um marco importante na minha evolução para o desenvolvimento web full-stack.

## ✨ Características do Projeto

- 🛒 **Plataforma de E-commerce:** Vitrine de roupas, navegação por produtos e simulação de compra.
- 📱 **Totalmente Responsivo:** Layout adaptado para diferentes tamanhos de tela (desktop e mobile).
- ✉️ **Sistema de E-mail (`mailer-src`):** Estrutura voltada para disparo de mensagens e comunicação com o cliente.
- 🗄️ **Banco de Dados Relacional (`store.sql`):** Modelagem de dados para gerenciar produtos, clientes e pedidos.

---

## 🛠️ Stack Tecnológica

- **Back-end:** PHP
- **Front-end:** JavaScript, CSS3, HTML5
- **Banco de Dados:** MySQL / MariaDB (Script `store.sql` incluso)
- **Hospedagem:** InfinityFree / Great-Site
